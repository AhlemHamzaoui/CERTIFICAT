# 🎓 Accelerated Course Certificate — Regression Analysis (Summer 2024)

This repository includes my certificate of completion for the accelerated course:

**"Regression Analysis: Understanding and Building Business and Economics Models"**  
Organized by **Avila University** (USA) in collaboration with **Carthage University**, Tunisia.

## 📚 Course Overview
This intensive summer program focused on:
- Building and interpreting **regression models**
- Understanding **business & economic data behavior**
- Working with **real-world datasets**
- Performing **model validation and evaluation**
- Applying regression analysis for **decision-making**

## 🛠️ Practical Work (TP)
The training included multiple hands-on sessions where I:
- Performed **data cleaning & preprocessing**
- Built **simple and multiple linear regression models**
- Analyzed **residuals and model fit**
- Used **statistical software** for model implementation

## 🎯 Outcomes
Through this program, I strengthened my skills in:
- **Statistical modeling & analysis**
- **Data-driven reasoning**
- **Interpreting economic/business insights**
